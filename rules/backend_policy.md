# Backend Access Policy

## Rules and Restrictions

1. **Backend Restricted**: The AI assistant MUST NEVER access, read, or modify any files or directories inside the `backend` folder.
2. **Frontend Scope**: The AI assistant is ONLY permitted to access and modify the `frontend` directory.
3. **Backend Change Requests**: If any work or modifications are required in the `backend` folder, the AI assistant MUST request the user to perform those changes by providing a clear, detailed plan of what is needed in the backend.
